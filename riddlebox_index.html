Riddle of the Week

There are five pilots, each operating a different aircraft in five hangars painted in different colors. Each pilot is from a different country, drinks a different beverage, and communicates in a different radio call sign.

No two pilots share the same aircraft, country, beverage, or call sign.

Clues:

  • The French pilot is in the red hangar.
  • The Brazilian pilot flies a cargo plane.
  • The German drinks black coffee.
  • The blue hangar is immediately to the left of the white hangar.
  • The pilot in the green hangar drinks tea.
  • The one using the “Bravo” call sign flies a passenger jet.
  • The yellow hangar hosts the pilot using “Echo” call sign.
  • The pilot in the middle hangar drinks water.
  • The Canadian pilot is in the first hangar.
  • The pilot using “Charlie” is next to the one flying a helicopter.
  • The one with a fighter jet is next to the pilot using “Echo”.
  • The pilot with the “Alpha” call sign drinks soda.
  • The Japanese pilot uses the “Delta” call sign.
  • The Canadian is next to the blue hangar.
  • The pilot using “Charlie” is next to the one who drinks juice.
